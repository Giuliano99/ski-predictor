# Tippabgaben Inbox

Hier werden lokal aus der Website exportierte Tippabgaben abgelegt.

1. Tipp in der Website speichern.
2. `Tipp exportieren` auswählen.
3. Die heruntergeladene JSON Datei in den Unterordner der passenden Tipprunde verschieben.
4. Die Auswertung mit dem im Importer README beschriebenen Befehl erzeugen.

Die Tippabgaben enthalten personenbezogene Spieldaten und werden von Git ignoriert.
Jede exportierte Datei enthält die Inhaltsversion der Tipprunde. Eine Datei wird nur ausgewertet, wenn diese Version exakt mit der veröffentlichten Tipprunde übereinstimmt.

Für den offenen Test ist der Zielordner `tip-round-2026-01-03`.
