# Eingang für Ergebnislisten

Lege hier repräsentative Ergebnislisten unverändert in ihrem Originalformat ab. Unterstützte Beispiele sind PDF, XLSX, CSV, HTML und Bilder.

Die Ergebnisdateien in diesem Ordner werden von Git ignoriert. Dadurch werden Namen und Ergebnisdaten von Kindern und Jugendlichen nicht versehentlich in das öffentliche Repository übertragen.

Besonders hilfreich sind:

1. ein typisches SVM Rennen
2. ein Landkreisrennen mit mehreren Altersklassen
3. ein Rennen mit zwei Läufen
4. eine Liste mit DNS, DNF und DSQ
5. ein Rennwochenende mit mehreren Einzelrennen
6. falls vorhanden ein Bayernliga oder DSV Qualifikationsrennen

Bitte Dateinamen und Dateiinhalte zunächst nicht verändern. Zusätzliche Informationen können in einer gleichnamigen Textdatei ergänzt werden.
