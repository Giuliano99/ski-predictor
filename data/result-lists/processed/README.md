# Verarbeitete Renndaten

Der PDF Extraktor schreibt normalisierte JSON Dateien in diesen Ordner. Die erzeugten Dateien können vollständige Namen Minderjähriger enthalten und werden deshalb nicht von Git erfasst.

Die JSON Dateien dienen im MVP als lokale Datenquelle. Vor einer Verwendung im Tippspiel müssen die erkannten Wertungsgruppen und Oberhachinger Starter geprüft werden.
